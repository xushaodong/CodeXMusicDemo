# CodeXMusicDemo (HarmonyOS ArkUI)

基于你的设计文档实现了一个现代化音乐播放器 UI（ArkTS/ArkUI），包含：

- 深浅色主题切换（右上角按钮）
- 竖屏/横屏自适应布局（宽 > 高判定为横屏）
- 黑胶唱片旋转动效（播放中旋转，暂停停止）
- 毛玻璃风格播放控制卡片
- 竖屏侧滑播放列表（右侧抽屉）
- 横屏常驻播放列表
- 进度条与音量条交互

## 主要文件

- `entry/src/main/ets/pages/Index.ets`

## 设计映射

- 颜色、圆角、间距、阴影、过渡时长按需求文档实现
- 组件结构：导航栏 / 黑胶唱片 / 播放控制 / 播放列表
- 交互：切歌重置唱片角度、点击背景关闭菜单、播放状态切换
